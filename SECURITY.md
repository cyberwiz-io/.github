# Security policy

Thanks for helping keep CyberWiz projects and the people who use them safe.

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report it privately instead:

1. Go to the affected repository's **Security** tab.
2. Click **Report a vulnerability**.

If that option isn't available, reach out through [cyberwiz.io](https://cyberwiz.io) and mention it is a security report. Please leave the details out of that first message.

Please include what you found, how to reproduce it, and what impact you think it has.

## What to expect

- An acknowledgment within 5 business days.
- An update on the fix plan once the issue is confirmed.
- Credit in the release notes if you'd like it.

## Scope

This policy covers repositories in the GitHub organization that contains this file. Problems in an upstream project (for example a CIS benchmark or a third-party tool) should go to that project's maintainers.

Only test against systems you own or have permission to test.
