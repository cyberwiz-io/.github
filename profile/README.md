# CyberWiz

**Practical security for teams that don't have a security department.**

Most security guidance assumes you have a security team. Most organizations don't. CyberWiz shares the tools, test notes, and checklists I use to help small public-sector, water, nonprofit, and data teams get their security in order without a big budget or a full-time security lead.

### What you'll find here

| | |
| --- | --- |
| 🧪 **Benchmark field notes** | What CIS benchmark audit steps actually look like in a live tenant today, plus scripts that help you test them |
| 📋 **Readiness kits** | Plain-English guides for security questionnaires, SOC 2 conversations, and CIS Controls IG1 |
| 🔐 **Cloud and identity tools** | Small, focused tools for Azure, Microsoft 365, and Entra ID, plus AI agent and MCP server security testing |

This org is new. Projects show up here once they've been tested and reviewed, so check back or watch the org.

### How the work gets done

- **Tested first.** Everything here runs in a lab before it ships.
- **Upstream first.** If a fix belongs in a CIS benchmark or an open-source project, it goes there, and this org links to it.
- **No client data. Ever.** Examples are built from public frameworks and lab environments.
